# BOSS直聘岗位采集器 使用说明（方案B：浏览器脚本，替代Browser Use）

## 一、为什么不用豆包内置浏览器直接抓了？

豆包内置浏览器（Browser Use）底层是 Playwright，通过 **CDP 协议**控制浏览器。它一连接就会留下两个自动化特征：

1. `navigator.webdriver = true`
2. 自动发送 `Runtime.enable` 这个 CDP 命令（主流反爬系统都查它）

BOSS直聘的风控脚本专门检测这两个特征：
- **浏览/搜索时**：可能暂时放行（所以偶尔能看到数据），但会逐步把你重定向到登录页；
- **登录环节检测最严**：直接让登录页反复刷新、跳转，导致"一直刷新、登录不上去"，并清空登录 cookie。

这是内置浏览器**底层**的特征，我们改不了它内部的 Playwright（网上的 stealth 补丁打不进去）。
**结论：凡是需要"在内置浏览器里登录 BOSS"的路都走不通。** 所以改成在**你自己的 Edge 浏览器**里用脚本采集——那里是正常浏览器，`navigator.webdriver=false`、没有 CDP，你本来就能正常登录。

> 安全原则：脚本只**被动读取页面自己已经拿到的数据**（镜像 joblist 接口响应），**不主动发请求、不自动投递、不自动打招呼**，和网页自身的 JS 待遇完全一样，检测风险极低。

## 二、三种形态（本机已验证：用★原生扩展）

> **2026-08-30 实测结论**：本机 Edge 的 Tampermonkey（MV3）导入脚本后一直提示"此脚本还未被执行"、无法注入；改用 **① Edge 原生解压扩展（MAIN world）一次成功**，为本机推荐方式。油猴脚本、纯书签作为备选保留（换电脑/油猴能正常注入时可用）。

| 形态 | 是否需要装扩展 | 体验 | 本机状态 |
|------|--------------|------|--------|
| **★① Edge原生解压扩展** `boss_collector_extension/` | 开发人员模式下"加载解压缩的扩展"选文件夹 | 浏览器直接注入、最可靠，手动翻页自动累积 | ✅ 已采用 |
| ② 油猴脚本 Tampermonkey `boss岗位采集器.user.js` | 需装 Tampermonkey | 自动常驻 | 本机MV3注入失败，已停用 |
| ③ 纯书签 Bookmarklet | 零安装 | 每次点一下书签 | 备选 |

### ★方式①：加载原生扩展（本机已用此方式）
1. Edge 打开 edge://extensions ，左下角打开"开发人员模式"；
2. 点"加载解压缩的扩展"，选择本目录下的 `boss_collector_extension` 文件夹（内含 manifest.json + content.js）；
3. 列表出现"BOSS直聘岗位采集器（求职助手）"并启用即完成；
4. 以后正常登录 BOSS、搜索筛选、翻页，右上角"🎯岗位采集"面板自动累积，点"导出JSON"发豆包。
5. 若以后改过 content.js，到 edge://extensions 该扩展卡片上点"重新加载/刷新"图标即可。

## 三、方案①：油猴脚本安装（推荐）

### 第1步：安装 Tampermonkey
1. 打开 Edge，右上角 `...` → 扩展 → 管理扩展；
2. 先在"扩展"页打开左下角"开发人员模式"；
3. 点"获取 Microsoft Edge 扩展"，搜索 **Tampermonkey（篡改猴）**，点"获取"安装。

### 第2步：导入脚本
1. 点浏览器右上角 Tampermonkey 图标 → "管理面板"；
2. 点"+"号（添加新脚本）；
3. 用记事本打开本目录的 `boss岗位采集器.user.js`，**全选复制**，粘贴覆盖编辑区里的默认内容；
4. 按 `Ctrl+S` 保存（脚本列表里出现"BOSS直聘岗位采集器"且开关为启用）。

### 第3步：采集
1. 在 Edge 正常登录 BOSS直聘；
2. 搜索关键词（如"测绘"）、设置城市/薪资/学历等筛选；
3. 进入搜索结果页后，**右上角会出现"🎯岗位采集"浮动面板**；
4. 你正常地**滚动 / 翻页**即可，每翻一页面板数字自动增加（自动去重）；
5. 觉得够了点面板上的 **导出JSON**，得到一个 `.json` 文件；
6. 把这个 `.json` 文件发给豆包，后续匹配评估、报告生成全自动。

## 四、方案②：纯书签安装（免装扩展）

### 第1步：调出收藏夹栏
Edge/Chrome 按 `Ctrl+Shift+B` 显示收藏夹栏。

### 第2步：安装书签
1. 双击打开本目录的 **`install_bookmarklet.html`**（用 Edge 打开）；
2. 页面上有个蓝色按钮"采集BOSS岗位"，**用鼠标把它拖到收藏夹栏**；
   - 若拖不动：右键收藏夹栏 →"添加页面"，名称填`采集BOSS岗位`，网址粘贴 `boss_bookmarklet.txt` 里的全部内容。

### 第3步：采集
1. 正常登录、搜索、筛选，停在搜索结果页；
2. 点收藏夹里的"采集BOSS岗位"，右上角出现浮动面板；
3. 点 **自动翻5页并采集**（脚本只点网页自带的"下一页"，间隔9~15秒模拟真人），或自己手动翻页；
4. 点 **导出JSON**，把文件发给豆包。

> 书签是"点一次才运行"，所以要先点书签、再翻页；油猴脚本是自动常驻，更省事。

---

## 五、导出之后：豆包这边怎么处理（复用智联同款流水线）

你把导出的 `.json` 发来后，豆包执行：

```
导出JSON → parse_joblist_api.py 解析（明文薪资/技能/链接）→ 去重 →
match_engine 匹配评分 → report_generator 生成HTML推荐报告
```

和智联招聘走的是**同一套**匹配引擎、同一套报告模板、同一个岗位库，自动按"公司+岗位"去重，跨平台优先保留 BOSS。

---

## 六、风控注意事项（保护账号）

1. 全程**你手动登录、手动判断岗位**，脚本不自动投递/打招呼；
2. 单次采集建议 ≤ 5 页（约150条），翻页间隔别低于几秒，不要高频连续抓；
3. 如果 BOSS 出现掉线、验证页、页面刷新：**当天停止，第二天再用**（开源项目共识：硬刚容易封号）；
4. 不要多设备同时频繁操作同一账号；
5. 采集器只在 `zhipin.com` 页面运行，数据只保存在你本地，不上传任何第三方。
