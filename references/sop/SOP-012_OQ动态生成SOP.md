# SOP-012：OQ 开放式问题动态生成标准操作流程（AI 动态生成 + 本地知识库记忆 · v0.5.1）

## 目的

用 **AI 动态生成 + 本地知识库记忆** 的方式处理网申开放式问题（OQ，Open Question），替代旧的"固定题库覆盖"方案，做到：任何问题都能生成个性化答案、答案基于用户真实经历、越用越聪明、所有数据保存在本地不上传服务器。

**核心原则：AI 负责基于用户信息底座生成个性化答案，用户负责审核和微调，答案自动存档到本地知识库，下次遇到相同/类似问题直接复用。**

## 前置条件

1. 用户已完成 `application_profile.json` 信息底座（13块中文key，含基本信息/教育/实习/项目/技能/家庭等）
2. 用户已安装本 skill，工作区目录存在 `oq_answers/` 知识库目录
3. 用户在线（AI 动态生成需要对话）
4. 遇到具体的网申开放式问题（如"为什么选择我们公司""你的职业规划""最大困难"等）

## 架构原理（为什么不用固定题库）

### 旧方案的问题
- 固定题库只有 8 类 28 题，不可能覆盖所有公司的所有问题
- 不同公司问的侧重点不同，同一道题答案也需要针对性调整
- 题库更新慢，无法快速响应新题型

### 新方案的优势
- **AI 动态生成**：任何问题都能基于用户真实经历生成个性化答案，不局限于固定题型
- **本地知识库记忆**：生成过的答案自动保存到 `oq_answers/公司名/`，越用越聪明
- **搜索复用**：下次遇到相同/类似问题，先查知识库，有就直接用，没有再生成
- **隐私安全**：所有答案保存在本地，不上传服务器
- **迭代优化**：答案不好可以反馈，AI 重新生成，持续优化

### 四层架构
```
第一层：固定题库（oq_generator.py）
  └─ 预生成 20-30 道最高频题，作为快速参考（保留，不删除）

第二层：AI 动态生成（主力）
  └─ 用户把问题发给 AI，AI 基于 application_profile.json 生成个性化答案

第三层：本地知识库（oq_kb.py + oq_answers/）
  └─ 生成的答案自动存档，支持搜索、查看、导出、统计

第四层：迭代优化
  └─ 用户反馈答案好坏，AI 重新生成，持续优化
```

## 标准操作流程

### 步骤 1：遇到 OQ 问题，发给 AI

**用户操作**：在网申页面遇到开放式问题时，把以下信息发给 AI：
- 公司名（必填，用于知识库归档）
- 岗位名（可选，用于针对性调整）
- 问题原文（必填）

**示例话术**：
```
帮我生成一个 OQ 答案：
公司：广州市城市更新规划设计研究院
岗位：测绘技术人员
问题：为什么选择我们公司？
```

### 步骤 2：AI 基于信息底座生成答案

**AI 操作**：
1. 读取 `application_profile.json`，获取用户真实经历
2. 结合公司名、岗位名、问题，生成个性化答案
3. 答案必须基于用户真实经历（实习/项目/技能/教育），不能编造
4. 答案结构：背景/经历 → 具体做法 → 成果/收获 → 与岗位的关联

**答案质量要求**：
- 必须基于用户真实经历，禁止编造
- 针对性强，结合公司和岗位特点
- 结构清晰，有具体事例和数据
- 字数适中（200-500字，根据问题调整）
- 语言正式但不生硬，符合网申场景

### 步骤 3：答案自动保存到知识库

**AI 操作**：生成答案后，自动调用 `oq_kb.py add` 命令，把答案保存到 `oq_answers/公司名/` 目录。

**保存格式**：JSON 文件，包含 qid、category、question、answer、company、created、updated、version、rating 等字段。

**用户无需手动操作**，AI 自动完成存档。

### 步骤 4：搜索复用已有答案

**用户操作**：遇到新问题时，可以先问 AI："知识库中有没有类似问题的答案？"

**AI 操作**：调用 `oq_kb.py search "关键词"` 搜索知识库，如果有匹配的答案，直接展示给用户，用户可以选择直接用或微调后用。

**示例话术**：
```
帮我搜一下知识库中有没有关于"职业规划"的答案
```

### 步骤 5：导出答案（可选）

**用户操作**：需要把某家公司的所有 OQ 答案导出为文档时，告诉 AI。

**AI 操作**：调用 `oq_kb.py export --company "公司名" -o 输出路径`，导出为 Markdown 文档。

**示例话术**：
```
把广州市城市更新规划设计研究院的所有 OQ 答案导出为 Markdown
```

## 知识库管理命令速查

| 命令 | 功能 | 示例 |
|---|---|---|
| `python oq_kb.py stats` | 统计知识库情况 | 查看有多少公司、多少答案 |
| `python oq_kb.py list` | 列出所有答案 | 查看所有存档 |
| `python oq_kb.py list --company "公司名"` | 列出指定公司答案 | 查看某家公司的所有答案 |
| `python oq_kb.py search "关键词"` | 搜索答案 | 按关键词搜索问题和答案 |
| `python oq_kb.py show --company "公司" --qid "1.1"` | 查看指定答案 | 查看某道题的完整答案 |
| `python oq_kb.py add --company "公司" --question "问题" --answer "答案"` | 添加答案 | 手动添加答案到知识库 |
| `python oq_kb.py export --company "公司" -o out.md` | 导出答案 | 导出某家公司所有答案为 Markdown |

**注意**：日常使用中，用户不需要手动输入这些命令，直接用自然语言告诉 AI 即可，AI 会自动调用对应命令。

## 答案迭代优化流程

如果生成的答案不满意：

1. **用户反馈**：告诉 AI 哪里不好（如"太笼统了""不够具体""太长了""换个角度"）
2. **AI 重新生成**：基于反馈重新生成答案
3. **自动更新版本**：新答案自动保存，version 字段 +1，保留历史版本
4. **用户评分**（可选）：用户可以给答案打分（1-5），帮助 AI 了解偏好

## 常见问题

### Q1：固定题库（oq_generator.py）还能用吗？
A：能，保留作为基础。最高频的 20-30 道题可以用 `python oq_generator.py gen` 预生成，作为快速参考。但遇到题库中没有的问题，用 AI 动态生成。

### Q2：AI 生成的答案会不会编造经历？
A：不会。AI 严格基于 `application_profile.json` 中的真实经历生成答案，禁止编造。如果信息底座中没有相关经历，AI 会如实告知，不会编造。

### Q3：知识库中的答案会上传到服务器吗？
A：不会。所有答案保存在本地 `oq_answers/` 目录，不上传任何服务器。该目录已加入 `.gitignore`，不会被提交到 GitHub。

### Q4：换电脑了，知识库怎么迁移？
A：直接复制 `oq_answers/` 目录到新电脑的工作区即可。所有答案都是 JSON 格式，跨平台兼容。

### Q5：答案生成慢怎么办？
A：AI 动态生成需要一定时间（通常 10-30 秒）。如果是高频题，可以提前用固定题库预生成；如果是遇到问题再生成，耐心等待即可。生成后会自动存档，下次遇到相同问题直接复用。

## 相关文件

- `application_profile.json` — 用户信息底座（AI 生成答案的数据源）

- `oq_kb.py` — 知识库管理器（list/search/show/add/export/stats）
- `oq_answers/` — OQ 答案知识库（按公司分目录，JSON 格式）
- `references/sop/SOP-011_网申模块SOP.md` — 网申模块总 SOP
