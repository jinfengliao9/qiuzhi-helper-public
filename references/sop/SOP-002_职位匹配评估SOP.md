# SOP-002：职位匹配评估标准操作流程

## 目的

对职位描述（JD）进行匹配度评估，从4个维度评估候选人与岗位的匹配程度，给出投递建议。

## 前置条件

1. 工作区目录已初始化
2. `resume_data.json`简历数据源已存在
3. 已获取目标岗位的JD文本或职位链接

## 操作步骤

### 步骤1：准备JD文本

**方式A：用户粘贴JD文本**
- 用户直接提供JD文本内容
- 保存为临时文件或直接作为参数传入

**方式B：用户提供职位链接**
- 尝试读取页面内容提取JD
- 如无法自动提取，由AI手动解析

**方式C：用户口头描述岗位**
- 整理成结构化JD文本

### 步骤2：运行匹配评估

```bash
python job_search.py rank --jd job_description.txt
```

或直接传入JD文本：
```bash
python job_search.py rank --text "JD文本内容"
```

脚本会自动：
1. 解析JD：公司、岗位、城市、薪资、经验要求、学历要求、技能要求、岗位职责
2. 与简历数据从4个维度匹配评分：
   - **技术匹配**（35%权重）：JD要求的技能，用户有哪些匹配，哪些缺失
   - **经验匹配**（30%权重）：实习经历、项目经历、岗位经验要求
   - **行为匹配**（15%权重）：软技能、出差接受度、学习能力等
   - **硬约束**（20%权重）：学历、城市、经验年限等硬性条件
3. 输出综合匹配度评分（0-100分）和投递建议

### 步骤3：查看匹配度报告

报告为HTML格式，保存在：
```
applications/rank_<公司>_<岗位>.html
```

报告包含：
- 综合匹配度环形图
- 4维度评分条
- 已匹配/缺失技能标签
- 硬约束检查结果
- JD信息解析

### 步骤4：解读匹配度评分

| 评分范围 | 建议 | 说明 |
|----------|------|------|
| 80分以上 | 强烈推荐投递 | 高度匹配，优势明显 |
| 65-79分 | 推荐投递 | 基本匹配，有一定优势 |
| 50-64分 | 可以尝试 | 部分匹配，需突出相关经历 |
| 50分以下 | 不太建议 | 匹配度较低，优先考虑更匹配的岗位 |

### 步骤5：给出投递建议

根据匹配度报告，向用户说明：
1. 匹配的亮点（哪些经历和技能正好对口）
2. 存在的gap（岗位要求但候选人没有的）
3. 建议：是否建议投递，简历中应该重点突出什么
4. **停下来询问用户**：是否继续生成定制简历？

## 验证方法

1. **JD解析验证**：检查解析出的公司、岗位、城市、薪资是否正确
2. **技能匹配验证**：检查已匹配/缺失技能是否合理
3. **评分合理性验证**：检查4维度评分是否符合实际情况
4. **报告完整性验证**：检查HTML报告是否包含所有必要内容

## 常见问题

### Q1：JD解析不完整

**A**：rank.py的JD解析基于规则匹配，格式不规范的JD可能解析不完整。此时由AI手动补充解析，或在报告中说明解析不完整的部分。

### Q2：技能匹配不准确

**A**：技能匹配基于关键词，用户技能列表中的名称需与JD中的名称尽量一致。如发现匹配不准确，可手动调整`resume_data.json`中的技能名称。

### Q3：匹配度评分不合理

**A**：匹配度评分是辅助参考，不能代替用户的主观判断。如认为评分不合理，可结合实际情况手动调整投递策略。

### Q4：如何提高匹配度

**A**：
1. 在简历中突出与JD相关的经历和技能
2. 使用JD中的关键词描述自己的经历
3. 补充JD要求但自己具备的技能
4. 针对岗位定制简历内容
