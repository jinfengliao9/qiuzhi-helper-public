# 求职工作区助手 - 快速入门指南

## 5分钟快速上手

### 第1步：了解工作区

所有求职相关文件统一存放在 `job-search-workspace/` 文件夹中。

核心文件：
- `job_search.py`：统一工作流引擎（推荐使用）
- `config.yaml`：统一配置文件
- `resume_data.json`：简历数据源（中文键名，直接修改）
- `jobs.json`：岗位库（已抓取的岗位信息）
- `PROJECT_NODE.md`：项目节点文档（全流程记录）

### 第2步：修改简历数据

编辑 `resume_data.json` 文件，填写你的个人信息、教育背景、实习经历、项目经历、技能清单等。

简历数据源使用中文键名，便于直接修改。例如：
```json
{
  "基本信息": {
    "name": "你的名字",
    "phone": "你的电话",
    "email": "你的邮箱",
    "city": "所在城市",
    "job_intention": "求职意向"
  },
  "教育背景": [...],
  "实习经历": [...],
  "项目经历": [...],
  "技能清单": {...}
}
```

### 第3步：生成简历

```bash
python job_search.py resume
```

脚本会自动生成4套模板的HTML+PDF简历，保存在 `cv/` 目录下。

用浏览器打开HTML文件查看效果，或直接使用PDF文件。

### 第4步：运行质量检查（可选但推荐）

```bash
python job_search.py quality check
```

检查简历数据、岗位库、申请记录、配置文件是否有问题。

## 完整求职流程

### 流程1：准备简历

1. 修改 `resume_data.json` 中的个人信息
2. 运行 `python job_search.py resume` 生成简历
3. 用浏览器打开HTML文件，检查效果
4. 如需调整，修改JSON后重新生成

### 流程2：寻找岗位

1. 在你本人 Edge 加载采集扩展并登录平台（BOSS/智联）
2. 你手动设置关键词和筛选条件、搜索翻页，扩展被动累积（BOSS可点"补全JD"，智联自带JD）
3. 点"导出JSON"发给 AI（详细步骤见SOP-006）
4. 出独立报告：`python boss_api/make_standalone_report.py 导出.json -o applications/报告.html`；或入库后 `python job_search.py jobs report`
5. 用浏览器打开报告，查看高匹配岗位

### 流程3：评估匹配度

1. 将感兴趣的岗位JD保存为文本文件
2. 运行 `python job_search.py rank --jd job_description.txt`
3. 查看匹配度报告，了解优势和差距
4. 根据匹配度决定是否投递

### 流程4：定制简历

1. 确认要投递的岗位
2. 运行 `python job_search.py apply --jd job_description.txt`
3. 脚本会先进行匹配评估，再生成定制简历
4. 检查定制简历，确保突出了与岗位相关的经历

### 流程5：面试准备

1. 收到面试通知后，运行：
   ```bash
   python job_search.py interview --company "公司名" --position "岗位名"
   ```
2. 查看面试准备报告，练习自我介绍
3. 参考面试题库（`interview-prep/`），准备专业问题
4. 如需模拟面试，可让AI扮演面试官进行练习

### 流程6：申请归档

1. 投递后，添加投递记录：
   ```bash
   python job_search.py outcome add --company "公司名" --position "岗位名"
   ```
2. 收到通知后，更新状态：
   ```bash
   python job_search.py outcome update --id <编号> --status "面试中"
   ```
3. 定期查看统计：
   ```bash
   python job_search.py outcome stats
   ```
4. 根据统计数据优化投递策略

## 岗位抓取快速指南

### 前置条件（Edge 扩展被动采集，v0.2.0 主路径）

1. Edge 已加载扩展 `boss_api/boss_collector_extension/`（MAIN world）
2. 已在**本人 Edge**（不是内置浏览器）登录目标平台
3. BOSS 补全JD时用户在线（遇验证页人工处理）

### 基本流程

1. **你搜索/筛选/翻页**：在 Edge 平台页面手动设置城市、薪资、经验、学历，正常翻页
2. **扩展被动累积**：右上角面板计数增长，自动去重；只镜像页面正常响应，不主动抓取
3. **BOSS补全JD（可选）**：点"补全BOSS的JD"，6-11秒/个拟人间隔，可停止；智联列表自带JD，跳过
4. **导出JSON**：点"导出JSON"，把文件发给 AI
5. **AI解析匹配**：parse_joblist_api / parse_zhaopin_api 映射为标准岗位
6. **出报告**：独立报告（不入库）或 import→rank→report 并入 `jobs.json`

### 风控策略

- **列表/智联JD**：纯被动，零额外请求，正常翻页即可
- **BOSS补JD**：6-11秒随机间隔、每10个长休息、可随时停止、标签保持前台、单次30-60个
- **通用原则**：不自动投递/打招呼，弹验证页立即停止且当天不再操作；旧 Browser Use/CDP 已归档

详细步骤请参考 `references/sop/SOP-006_岗位抓取SOP.md`。

## 配置快速指南

### 查看配置

```bash
python job_search.py config show
```

### 修改配置

直接编辑 `config.yaml` 文件，主要配置项：

```yaml
# 匹配权重（总和应为1.0）
matching:
  weights:
    tech_match: 0.35
    experience_match: 0.3
    behavior_match: 0.15
    hard_constraints: 0.2

# 抓取配置（反爬策略）
scraper:
  default_platform: zhaopin
  default_count: 10
  detail_interval: 4

# 平台配置
platforms:
  zhaopin:
    enabled: true
    search_url: "https://www.zhaopin.com/jobs"
  boss:
    enabled: true
    search_url: "https://www.zhipin.com/web/geek/jobs"
```

### 验证配置

```bash
python job_search.py config validate
```
